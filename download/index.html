Préversion

Les versions publiées sont des préversions beta. L’application vérifie le flux de mise à jour trois secondes après son lancement et te propose la suivante quand elle sort.

Signature vérifiée

L’installeur Windows est publié avec sa signature minisign .sig, celle que le système de mise à jour intégré vérifie avant de remplacer une version installée.

Windows

Installateur publié

Installeur NSIS 64 bits, se met à jour en place.

Télécharger — Windows

Lecture de la dernière version publiée…

Prérequis

Windows 10 ou 11, 64 bits.

Installation

  1. 1 Télécharge l’installeur .exe.
  2. 2 Windows SmartScreen affiche un avertissement : l’installeur n’est pas signé par un certificat commercial. Clique sur « Informations complémentaires », puis sur « Exécuter quand même ».
  3. 3 Suis l’installeur jusqu’au bout.
  4. 4 Au premier lancement, colle l’adresse de ton portail Aimaira. N’importe quelle page du portail convient.

Les mises à jour suivantes s’installent depuis l’application : elle vérifie le flux trois secondes après son lancement.

Android

Installateur publié

APK universel : arm64-v8a, armeabi-v7a et x86_64 dans le même fichier.

Télécharger — Android

Lecture de la dernière version publiée…

Prérequis

Android 7.0 ou plus récent.

Installation

  1. 1 Télécharge l’APK.
  2. 2 Ouvre le fichier téléchargé. Android demande d’autoriser l’installation depuis cette source : accorde-la à ton navigateur ou à ton gestionnaire de fichiers.
  3. 3 Valide l’invite d’installation du système.
  4. 4 Au premier lancement, colle l’adresse de ton portail.

Android compare les versionCode, pas les noms de version : un APK dont le code n’est pas supérieur à celui installé n’est pas vu comme une mise à jour par le système.

iOS

Installateur publié

IPA non signé, installé par AltStore ou SideStore avec ton propre identifiant Apple.

Télécharger — iOS

Lecture de la dernière version publiée…

Prérequis

iOS 15 ou plus récent, et AltStore ou SideStore déjà installé.

Installation

  1. 1 Installe AltStore ou SideStore sur ton iPhone.
  2. 2 Dans l’application, ajoute la source ci-dessous.
  3. 3 Installe BetterAimaira depuis cette source.
  4. 4 Au premier lancement, colle l’adresse de ton portail.

L’IPA est compilé sans signature de code : AltStore et SideStore le resignent avec ton compte. Avec un compte Apple gratuit, le certificat est à renouveler tous les sept jours.

macOS

Compilation locale

Aucun bundle publié pour l’instant : la compilation locale produit le .app et le .dmg.

Prérequis

Bun 1.2 ou plus, Rust 1.80 ou plus, et les outils en ligne de commande Xcode.

Installation

git clone https://github.com/fr-timothe/BetterAimaira.git
cd BetterAimaira
bun install
bun run desktop:build

Le bundle est écrit dans src-tauri/target/release/bundle/. Une fois installé, il lit le même flux de mise à jour que les autres plateformes.

Linux

Compilation locale

Aucun paquet publié pour l’instant : la compilation locale produit l’AppImage et le .deb.

Prérequis

Bun 1.2 ou plus, Rust 1.80 ou plus, et les prérequis de plateforme Tauri (libwebkit2gtk-4.1-dev et ses compagnons).

Installation

git clone https://github.com/fr-timothe/BetterAimaira.git
cd BetterAimaira
bun install
bun run desktop:build

Le mot de passe enregistré passe par le Secret Service de la session, donc par GNOME Keyring ou KWallet selon ton bureau.
