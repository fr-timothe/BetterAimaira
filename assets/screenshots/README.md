Rules for anything committed here:

- **No real student data.** No name, photo, identifier, grade, room or portal hostname belonging to
  a real person or a real instance. Capture against anonymized data, or blur before committing.
- PNG, at the app's native resolution, no device frame, no drop shadow baked in.
- Keep the file names above; the README references them directly.

Until the files exist, the README's screenshot row renders as broken images. Adding them is the last
step before a public release, not a blocker for development.
